JavaScript ES6 - Variáveis

Nome das variáveis

  • Os nomes podem iniciar com $ ou letras
  • Case sensitive - carro é diferente de Carro
  • Não utilizar palavras reservadas
  • Camel Case - por padrão criamos variáveis assim: precoCarro

Declaração das variáveis

  • let carro = "Fiat";
    console.log(carro);

Ordem da declaração

  • console.log(carro);
    let carro = "Fiat";
    // Retorna undefined
  • let marca = "Chevrolet";
    console.log(marca);
    // Retorna Chevrolet

Recaptulando

  • var e let eu consigo alterar o valor

  • const eu não consigo alterar o valor
